03 / projects

Selected work

Oxtore

Heading to production

A B2B2C marketplace for North African retailers, where stores supply resellers on consignment and track who sold what.

Situation
The client needed wholesale, consignment and retail sales in one platform, but couldn't afford the infrastructure a microservices cluster demands.
Task
Keep clean domain boundaries while cutting hosting cost, and plug in an existing Angular frontend built with different naming and ID types.
Action
Consolidated identity, product, staff, store and stock services into a Spring Boot monolith. Modelled supply requests and per-store stock, added AOP-based store authorization by role, and wrote a thin adapter layer so the frontend worked unchanged.
Result
End-to-end flows passed for store creation through reseller stock. The multi-device client demo landed, and the project is moving to production on a single OVH server. Built as part of a small team.

  • WebSocket
  • Docker

Doctime

In progress

A patient and doctor appointment platform, built as a reference for how I structure event-driven Java systems.

Situation
Booking systems are deceptively hard: double-booking, notifications and availability all fight over the same data.

Design four to six services that stay testable and run on an 8 GB laptop, then deploy to Kubernetes.

Core architecture in place. Next up are the CI/CD pipeline, the cluster rollout and an LLM assistant backed by RAG.

SentinelEyes

Completed

A tamper-evident audit trail for multi-site hospital networks, where every record can be traced and verified.

Situation
In regulated healthcare, an audit log is only worth something if nobody, including an admin, can quietly rewrite it.
Task
Make every audit event verifiable across sites without a central point of trust.
Action
Signed events with RSA-PSS, chained them by hash, published them over RabbitMQ to per-site consumers, and built public-key registration plus an Angular verification view.
Result
Any altered or removed record breaks the chain and is flagged on verification, at every site.
  • Python
  • RabbitMQ
  • Angular
  • RSA-PSS
  • PostgreSQL
